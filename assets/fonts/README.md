# Embedded fonts

`DejaVuSansMono.ttf` is the default Glyphweld runtime face. It is embedded into
the build output; applications do not load a system font at runtime.

- Family: DejaVu Sans Mono, Book
- Upstream release: DejaVu Fonts 2.37
- Upstream source: `dejavu-fonts/dejavu-fonts` tag `version_2_37`
- SHA-256: `54bf827eb99404e8f430c330ad30f063334f637eba0109b6a18d4f566a8e9dd8`
- License: [LICENSE-DejaVu.txt](LICENSE-DejaVu.txt)

It is intentionally one monospaced face. Font selection, fallback-face chains,
and user-supplied fonts are later work.
